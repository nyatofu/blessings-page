# 礼物弹窗效果

一个温馨的网页礼物弹窗效果，点击确定后会持续弹出带有祝福语的小窗口。

## 效果预览

- 初始页面显示一个标题为"一份礼物"的窗口
- 点击"确定"按钮后，开始持续弹出祝福窗口
- 每个窗口显示不同的祝福语，颜色随机
- 窗口具有淡入和轻微弹跳动画效果
- 用户可以点击任意窗口来关闭它

## 功能特性

### 1. 初始窗口

- 标题为"一份礼物"
- 内容为"这是一份礼物，要打开吗"
- 只有"确定"按钮，没有关闭选项
- 窗口无法通过控制按钮关闭

### 2. 祝福窗口

- 标题为"💝提示"
- 随机显示20条祝福语中的一条
- 7种不同颜色主题（淡紫色、淡绿色、淡粉色、淡青色、淡红色、淡橙色、淡黄色）
- 每150毫秒弹出一个新窗口

### 3. 窗口管理

- 最多同时显示300个窗口
- 超过300个时，自动关闭最老的窗口
- 窗口关闭时有淡出和缩小动画

### 4. 视觉设计

- 浅蓝色渐变背景
- 窗口具有圆角和阴影效果
- 居左对齐的标题栏
- 温馨的色彩搭配

## 技术实现

- 使用纯HTML、CSS和JavaScript实现
- CSS动画实现淡入淡出和弹跳效果
- JavaScript控制窗口生成和管理
- 随机位置和颜色分配
- 队列管理确保窗口数量控制

## 使用方法

直接在浏览器中打开HTML文件即可使用。点击初始窗口的"确定"按钮开始体验礼物弹窗效果。
